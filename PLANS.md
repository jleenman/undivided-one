## Milestone 1 — Initial evidence correction

Tasks ECHAD-001 through ECHAD-009 establish the claim matrix and audit lexical, methodological, relational, pneumatological, historical, model-comparison, definitional, and key-text claims. Each output needs evidence blocks, alternatives, confidence, sources, NL/EN impact, and discrete proposals. No unapproved canonical changes.

## Milestone 2 — Core compression and research architecture

Tasks ECHAD-010 through ECHAD-012. ECHAD-010 starts only when ECHAD-002–009 are `review` or `done`. Target NL length: 8,219–9,483 rendered words (25–35% below 12,644); EN remains semantically parallel. Deliver an outline, keep/move/remove matrix, separate NL/EN drafts, change log, subessay structure, and parity review.

## Milestone 3 — Site quality

ECHAD-013 validates build, typecheck, lint, tests, links, metadata, canonical/hreflang, sitemap, accessibility, mobile layout, and downloads. Safe technical fixes remain isolated; theology remains proposal-gated.

## Milestone 4 — Recurring research

ECHAD-090 maintains at least three executable `ready` prompts, exactly one bounded task per run.

## Validation

Run the canonical Nuxt checks: `npm test`, `npm run typecheck`, and `npm run generate`. Add focused link/content checks from the task prompt. Record environment failures; never reinterpret failure as success. Recheck live NL/EN routes for content work.
