# Echad research program

This directory is the audit trail for the Undivided One content program. Start with [STATUS.md](STATUS.md), follow [../../IMPLEMENT.md](../../IMPLEMENT.md), and execute one prompt from [prompts/](prompts/) with `$echad-research`.

Canonical theological text is not stored here. Reports contain evidence; `revisions/main-essay/PROPOSALS.md` contains human-review gates; implementation occurs only after explicit approval.

Key records: `CLAIM-REGISTER.md`, `DECISIONS.md`, `SOURCE-POLICY.md`, `CONTENT-ARCHITECTURE.md`, and `AUTOMATIONS.md`.
